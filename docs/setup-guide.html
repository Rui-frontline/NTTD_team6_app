はじめに

「VS Code」「GitHub」「Git」って何？

この3つは名前が似ていますが、役割は全然違います。

  • VS Code … コードを書くためのアプリ。Word のようなもの。
  • GitHub … 書いたコードをネット上に置いて、チームで共有する場所。Google ドライブのようなもの。
  • Git … 手元のコードと GitHub をやりとりするための道具。VS Code の裏側で動きます。
01

VS Code をインストールする

必須 約10分

Visual Studio Code（略して VS Code）は、コードを書くための無料アプリです。Microsoft が配布しています。

インストール手順Windows

  1. code.visualstudio.com を開きます。

  2. 青い 「Download for Windows」 ボタンを押します。パソコンに合ったものが自動で選ばれるので、細かい種類は気にしなくて大丈夫です。

  3. ダウンロードされた VSCodeUserSetup-x64-〇〇.exe をダブルクリックします。ブラウザの右上や、画面下の「ダウンロード」フォルダにあります。

  4. 「同意する」 を選んで、あとは 「次へ」 を押し続けます。

    途中の「追加タスクの選択」画面では、「PATH への追加」にチェックが入っていることだけ確認してください（初期状態で入っています）。

  5. 「インストール」 → 終わったら 「完了」。VS Code が起動します。

よくあるつまずき

「WindowsによってPCが保護されました」という青い画面が出たら

公式サイトからダウンロードしたファイルなので問題ありません。「詳細情報」をクリック → 下に出てくる 「実行」 を押してください。

インストール手順Mac

  1. code.visualstudio.com を開きます。

  2. 青い 「Download for macOS」 ボタンを押します。M1/M2/Intel などの違いは自動で判別されるので、気にしなくて大丈夫です。

  3. ダウンロードした zip をダブルクリックして解凍します（自動で解凍されることもあります）。

  4. 出てきた 「Visual Studio Code」 のアイコンを、「アプリケーション」フォルダにドラッグ＆ドロップします。これがインストール作業です。

    Finder を開いて、左側のサイドバーの「アプリケーション」に放り込めば OK です。

  5. アプリケーションフォルダから Visual Studio Code をダブルクリックして起動します。「インターネットからダウンロードされたアプリです」と聞かれたら 「開く」 を押します。

日本語表示にする（おすすめ）

初期状態では英語表示です。日本語化しておくと後がラクになります。

  1. VS Code の左端にある、四角が4つ並んだアイコン（Extensions＝拡張機能）をクリックします。ショートカットは Ctrl + Shift + Xショートカットは ⌘ + Shift + X。

  2. 検索欄に Japanese と入力します。

  3. 一番上に出てくる 「Japanese Language Pack for Visual Studio Code」 の Install を押します。

  4. 右下に「再起動しますか？」と出るので Change Language and Restart を押します。日本語になれば成功です。

ここまでできたら OK
  • VS Code が起動する
  • メニューが日本語で表示されている（日本語化した場合）
02

GitHub のアカウントを作る

必須 約15分

GitHub は、チームでコードを共有・管理するためのサービスです。ここにアカウントがないと、チームの作業に参加できません。無料です。

アカウント登録

  1. github.com/signup を開きます。

  2. メールアドレスを入力します。個人のアドレスで構いません。

  3. パスワードを決めます。15文字以上、または「8文字以上＋数字＋小文字」が必要です。

  4. ユーザー名を決めます。半角英数字とハイフンのみ。世界で一人ひとつなので、埋まっていたら数字などを足してください。

    このユーザー名はチーム全員に見えます。あとから変えると面倒なので、無難なものにしておくのがおすすめです（例：tanaka-hana）。

  5. 「製品アップデートを受け取るか」は n（受け取らない）で構いません。

  6. パズル認証が出ます。指示どおりに画像を回転させるなどして進めてください。

  7. 「Create account」 を押すと、登録したメールアドレスに8桁のコードが届きます。それを入力すれば登録完了です。

  8. そのあと「何人のチームですか？」などのアンケートが出ますが、スキップして構いません。

2段階認証（2FA）を設定する

GitHub では、コードを扱うユーザーに2段階認証の設定が求められます。後回しにすると作業中にロックされて困るので、今のうちにやってしまいましょう。スマホを用意してください。

  1. 右上のアイコン → Settings → 左メニューの Password and authentication を開きます。

  2. Two-factor authentication の Enable を押します。

  3. スマホに認証アプリを入れます。Google Authenticator か Microsoft Authenticator（どちらも無料）が定番です。

  4. 画面に出た QR コードを、そのアプリでスキャンします。アプリに6桁の数字が表示されるので、GitHub の画面に入力します。

  5. リカバリーコードが表示されます。スマホをなくしたときの最後の命綱です。必ずダウンロードするか、スクリーンショットを撮って保存してください。

重要

リカバリーコードを保存せずにスマホを失くすと、アカウントに二度と入れなくなります。ダウンロードしたファイルを、自分がわかる場所に置いておいてください。

チームに参加する

  1. できあがったユーザー名をチームのチャットに送ってください。こちらから招待を送ります。

  2. 招待メールが届いたら 「Join」「Accept invitation」 といったボタンを押してください。これでチームのコードが見えるようになります。

ここまでできたら OK
  • GitHub にログインできる
  • 2段階認証が有効になっている
  • リカバリーコードを保存した
  • チームにユーザー名を伝えた
03

Git をインストールする

できる人だけ 約15分
ここから先について

ここはできる人だけで大丈夫です。難しそうだと感じたら STEP 02 で止めて構いません。当日みんなで一緒にやります。

Git は、手元で書いたコードを GitHub に送ったり、他の人の変更を取り込んだりするための道具です。ここからは「ターミナル」に文字を打ち込む作業が出てきます。

ターミナルとは

マウスの代わりに文字で命令を打ち込む画面のことです。黒い画面に文字だけが並んでいるアレです。

VS Code の中から開けます。上のメニューの 「ターミナル」→「新しいターミナル」 を選ぶと、画面の下半分に出てきます。ショートカットは Ctrl + Shift + @ショートカットは ^ + Shift + @。

命令は1行打つごとに Enter を押します。以下のコマンドは右側の COPY ボタンでコピーして、ターミナルに貼り付けてください。

インストール手順Windows

やり方は2つあります。方法Aのほうが速いですが、うまくいかなければ方法Bにしてください。

方法A：コマンドで入れる

ターミナルに次を貼り付けて Enter。

winget install --id Git.Git -e --source winget

「使用許諾に同意しますか」と聞かれたら Y を押して Enter。インストールが終わったら、ターミナルを一度閉じて開き直してください（そうしないと git が認識されません）。

方法B：インストーラーで入れる

  1. git-scm.com/download/win を開き、「64-bit Git for Windows Setup」 をダウンロードします。

  2. ダウンロードした exe を実行します。設定画面がたくさん出てきますが、基本は「Next」を押し続けて大丈夫です。

  3. 途中の 「Choosing the default editor used by Git」 だけは、プルダウンから 「Use Visual Studio Code as Git's default editor」 を選んでおくと後がラクです。

  4. 最後まで進めて 「Install」→「Finish」。

インストール手順Mac

Mac には Git を入れる仕組みが最初から用意されています。ターミナルに次を貼り付けて Enter を押してください。

git --version
  • git version 2.〇〇 のように表示されたら → すでに入っています。次の「最初の設定」へ進んでください。
  • 「コマンドラインデベロッパツールが必要です」というダイアログが出たら → 「インストール」 を押して待ちます（5〜10分かかります）。終わったらもう一度 git --version を試してください。

ダイアログが出ない場合は、次のコマンドでインストーラーを呼び出せます。

xcode-select --install

インストールできたか確認する

ターミナルで次を実行します。

git --version

git version 2.〇〇.〇 のように表示されれば成功です。数字は違っていて構いません。

最初の設定（名前とメールを登録する）

「誰が変更したか」を記録するために、名前とメールアドレスを Git に教えます。この設定をしないと、後でコードを送るときにエラーになります。

下のコマンドの "..." の中身を自分のものに書き換えてから実行してください（ダブルクォートは残します）。

git config --global user.name "GitHubのユーザー名"
git config --global user.email "GitHubに登録したメールアドレス"

続けて、新しく作るときの初期ブランチ名を main に揃えておきます（こちらは書き換え不要です）。

git config --global init.defaultBranch main

設定できたか、次のコマンドで確認できます。自分の名前とメールが表示されれば OK です。

git config --global --list
ここまでできたら OK
  • git --version でバージョンが表示される
  • git config --global --list に自分の名前とメールが出る

つまずいたときは

詰まるのは普通のことです。ここに書いてあることだけ守ってもらえれば、あとはこちらで対応できます。

  1. そのままの画面をスクリーンショットで撮ってください。エラーの文章は、そのまま見せてもらうのが一番早いです。Windows は Windows + Shift + S で範囲を選んで撮れます。Mac は ⌘ + Shift + 4 で範囲を選んで撮れます。

  2. チームのチャットに、画像と「どのSTEPの何番でつまずいたか」を送ってください。

  3. エラーの文章を勝手に要約せず、そのまま貼ってもらえると助かります。

やらないでほしいこと

ネットで見つけた「解決方法」のコマンドを、意味がわからないまま実行しないでください。パソコンの設定が壊れることがあります。まず聞いてください。

用語集

ターミナル
マウスではなく文字で命令を打ち込む画面。VS Code の「ターミナル」メニューから開けます。「コマンドプロンプト」「シェル」もほぼ同じ意味で使われます。
コマンド
ターミナルに打ち込む命令文のこと。1行打って Enter を押すと実行されます。
インストール
アプリをパソコンに入れて使える状態にすること。
リポジトリ（repo）
GitHub 上の、ひとつのプロジェクト用のフォルダ。チームのコードはここに入ります。
クローン（clone）
GitHub にあるリポジトリを、自分のパソコンにコピーしてくること。
コミット（commit）
変更に名前をつけて記録すること。ゲームのセーブに近い作業です。
プッシュ（push）
自分のパソコンでの変更を GitHub に送ること。
プル（pull）
GitHub にある他の人の変更を、自分のパソコンに取り込むこと。
ブランチ（branch）
作業を枝分かれさせる仕組み。他の人の作業を壊さずに自分の変更を試せます。
拡張機能
VS Code に後から追加できる便利機能。日本語化もこれで行います。
